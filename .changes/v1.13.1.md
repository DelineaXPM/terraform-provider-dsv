## v1.13.1 - 2026-10-23

### 🤖 CI & Build

- Release tooling works under Go 1.26: goreleaser v1 → v2.9.0 (config migrated to version 2), tfplugindocs v0.18.0 → v0.25.0 (old one carried an expired HashiCorp PGP key). windows/arm (32-bit) is no longer built, as Go 1.26 removed that port.
- Release job timeout raised from 15 to 30 minutes (the v1.13.0 build alone took 9m13s). Goreleaser's Slack announce is disabled; the GitHub Slack app already posts releases. Fixed a stray quote in the Slack env templates that broke the webhook URL.

### 🔒 Security

- Build with Go 1.26.10 (from 1.26.8) to fix CVE-2026-56857, a Critical Go standard library vulnerability on Windows. Update golang.org/x/net to v0.60.0 (from v0.59.0), fixing five HTTP/2 vulnerabilities that govulncheck found reachable.
